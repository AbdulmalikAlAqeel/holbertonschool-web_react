# Task 0: Creating an interface for a student

This project is part of the Holberton School TypeScript curriculum. It demonstrates the basics of TypeScript, including interfaces, array typing, and Vanilla JavaScript DOM manipulation.

## Requirements

- Allowed editors: `vi`, `vim`, `emacs`, `Visual Studio Code`
- All files end with a new line.
- Code is transpiled on Ubuntu 18.04 using Webpack and TypeScript.
- TypeScript compiler should not show any warnings or errors when compiling.

## Files Description

- **`js/main.ts`**: Contains the TypeScript code where the `Student` interface is defined, student objects are created, stored in an array, and dynamically rendered into an HTML table using the DOM.
- **`tsconfig.json`**: TypeScript compiler configuration file.
- **`webpack.config.js`**: Webpack configuration file for bundling scripts.
- **`package.json`**: Project dependencies and scripts.
- **`.eslintrc.js`**: ESLint configuration file for linting TypeScript code.
